# Portfolio Dominique Othniel

Site statique (`index.html`, `style.css`, `script.js`, images PNG).

## Modifier un projet (site, image, description)

Ouvre **`projects.js`**. Chaque projet a notamment :

| Champ | Rôle |
| --- | --- |
| `url` | Lien du site |
| `image` | Fichier image dans ce dossier (ex. `mon-projet.png`) |
| `images` | Plusieurs images (galerie), à la place de `image` |
| `description.fr` / `description.en` | Texte sous la carte |
| `alt.fr` / `alt.en` | Texte alternatif de l'image |

Pour un nouveau projet : copier un bloc existant, changer les champs, déposer le PNG à la racine du site. Recharger la page.
